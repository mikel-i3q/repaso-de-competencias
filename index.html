Repaso de JavaScript

Resumen de los conceptos básicos trabajados en clase.

1. Variables y tipos
Explicación

Las variables guardan datos. Usamos let (puede cambiar), const (no cambia) y var (antigua, mejor evitar). Los tipos básicos son: string, number, boolean, null y undefined.

Ejemplo de código
let nombre = "Ana";       // string
const edad = 20;          // number
let activo = true;        // boolean
let sinValor = null;      // null

console.log(typeof nombre); // "string"
console.log(typeof edad);   // "number"
¿Qué hace?

Declaramos cuatro variables de distintos tipos. Con typeof podemos saber qué tipo de dato tiene una variable.

2. Operadores
Explicación

Los operadores realizan operaciones sobre valores. Los hay aritméticos + - * / %, de comparación === !== > < y lógicos && || !.

Ejemplo de código
let a = 10, b = 3;
console.log(a + b);          // 13
console.log(a % b);          // 1 (resto de la división)
console.log(a === 10);       // true
console.log(a > b && b > 0); // true (los dos son ciertos)
¿Qué hace?

Muestra operaciones básicas. El % devuelve el resto de la división. El === compara valor Y tipo, no solo el valor.

3. Condicionales
Explicación

Permiten ejecutar código solo si se cumple una condición. Usamos if, else if y else.

Ejemplo de código
let nota = 7;

if (nota >= 9) {
    console.log("Sobresaliente");
} else if (nota >= 5) {
    console.log("Aprobado");
} else {
    console.log("Suspendido");
}
¿Qué hace?

Comprueba el valor de nota y muestra un mensaje distinto según el rango. Con nota 7 entra en el else if y muestra "Aprobado".

4. Bucles
Explicación

Repiten un bloque de código. El for se usa cuando sabemos cuántas veces, el while mientras se cumpla una condición, y for...of para recorrer arrays.

Ejemplo de código
for (let i = 1; i <= 5; i++) {
    console.log("Vuelta " + i);
}

let frutas = ["manzana", "pera", "uva"];
for (let fruta of frutas) {
    console.log(fruta);
}
¿Qué hace?

El primer bucle imprime "Vuelta 1" hasta "Vuelta 5". El segundo recorre el array e imprime cada fruta.

5. Arrays
Explicación

Un array es una lista ordenada de valores. Los métodos más útiles: push, pop, splice, map, filter.

Ejemplo de código
let frutas = ["manzana", "pera", "uva"];

frutas.push("naranja");   // añade al final → 4 elementos
frutas.pop();             // elimina el último → vuelve a 3

let mayusculas = frutas.map(f => f.toUpperCase());
// ["MANZANA", "PERA", "UVA"]

let cortas = frutas.filter(f => f.length <= 4);
// ["pera", "uva"]
¿Qué hace?

push añade un elemento y pop lo elimina. map devuelve un nuevo array transformado. filter devuelve solo los que cumplen la condición.

6. Funciones
Explicación

Bloque de código reutilizable. Puede recibir parámetros y devolver un valor con return. Las funciones flecha (=>) son una forma más corta de escribirlas.

Ejemplo de código
// Función clásica
function sumar(a, b) {
    return a + b;
}

// Función flecha
const multiplicar = (a, b) => a * b;

console.log(sumar(3, 4));        // 7
console.log(multiplicar(3, 4));  // 12
¿Qué hace?

Define dos funciones que hacen operaciones distintas. La función flecha es más compacta y se usa mucho con map y filter.

7. DOM
Explicación

El DOM es la representación del HTML en JavaScript. Nos permite seleccionar y modificar elementos de la página.

Ejemplo de código
// Seleccionar un elemento
const titulo = document.getElementById('miTitulo');

// Modificarlo
titulo.textContent = 'Nuevo título';
titulo.style.color = 'red';

// Seleccionar varios
const parrafos = document.querySelectorAll('p');
¿Qué hace?

Selecciona un elemento por su id y cambia su texto y color. Con querySelectorAll podemos seleccionar varios elementos a la vez.

8. Eventos
Explicación

Los eventos permiten reaccionar a acciones del usuario: clic, tecla pulsada, pasar el ratón... Se capturan con addEventListener o directamente con onclick en el HTML.

Ejemplo de código
const boton = document.getElementById('miBoton');

boton.addEventListener('click', function() {
    alert('¡Hiciste clic!');
});
¿Qué hace?

Cuando el usuario hace clic en el botón, se ejecuta la función y aparece un alert. Es la base de toda interactividad en la web.

9. Math
Explicación

El objeto Math tiene métodos matemáticos ya integrados en JavaScript.

Ejemplo de código
Math.round(4.6);   // 5  → redondea al más cercano
Math.floor(4.9);   // 4  → siempre hacia abajo
Math.ceil(4.1);    // 5  → siempre hacia arriba
Math.random();     // número aleatorio entre 0 y 1
Math.max(3, 8, 1); // 8
Math.min(3, 8, 1); // 1

// Número aleatorio entre 1 y 10:
Math.floor(Math.random() * 10) + 1;
¿Qué hace?

Muestra los métodos de redondeo y cómo generar un número aleatorio en un rango combinando Math.random() con Math.floor().

10. Strings
Explicación

Los strings son cadenas de texto. Tienen métodos muy útiles para manipularlos.

Ejemplo de código
let texto = "  Hola Mundo  ";

texto.trim()                // "Hola Mundo" (quita espacios)
texto.toUpperCase()         // "  HOLA MUNDO  "
texto.includes("Mundo")     // true
texto.replace("Mundo","JS") // "  Hola JS  "

// Template literals (insertar variables en texto):
let nombre = "Ana";
console.log(`Hola, ${nombre}!`); // "Hola, Ana!"
¿Qué hace?

Muestra los métodos más frecuentes. Los template literals (comillas invertidas) permiten meter variables dentro del texto de forma cómoda.

11. Fechas
Explicación

El objeto Date permite trabajar con fechas y horas. Se crea con new Date().

Ejemplo de código
const ahora = new Date();

ahora.getFullYear(); // año actual (ej: 2025)
ahora.getMonth();    // mes (ojo: enero = 0, diciembre = 11)
ahora.getDate();     // día del mes (1-31)
ahora.getDay();      // día de la semana (0 = domingo)
ahora.getHours();    // hora (0-23)
¿Qué hace?

Crea un objeto con la fecha y hora actuales y accede a sus partes. Importante: getMonth() empieza en 0, así que hay que sumarle 1 para mostrar el mes real.

12. Formularios
Explicación

Con JavaScript leemos los valores de los campos con .value, los validamos y mostramos mensajes de error si algo falla.

Ejemplo de código
const nombre = document.getElementById('nombre').value.trim();
const edad   = document.getElementById('edad').value;

if (nombre === '') {
    alert('El nombre es obligatorio');
    return;
}
if (edad < 0 || edad > 120) {
    alert('Edad no válida');
    return;
}
¿Qué hace?

Lee dos campos, los valida y detiene la ejecución con return si algo falla. Es exactamente lo que hacemos en el proyecto CRUD de clase.

13. Errores típicos
Explicación

Estos son los errores más frecuentes al empezar con JavaScript. Conocerlos te ahorra mucho tiempo de depuración.

= vs == vs ===
let x = 5;
x == "5"   // true  (solo compara valor)
x === "5"  // false (compara valor Y tipo)
// Usa siempre === para comparar
getMonth() empieza en 0
new Date().getMonth() // enero=0, diciembre=11
// Solución: sumar 1
new Date().getMonth() + 1
El script va antes del HTML
// Si pones el script en el <head>, el HTML aún no existe
// y querySelector devuelve null.
// Solución: pon el <script> justo antes de </body>
push no devuelve el array
let arr = [1, 2];
let resultado = arr.push(3); // resultado = 3 (la nueva longitud!)
// El array modificado es arr, no resultado
Olvidar .trim() al validar inputs
input.value === ""         // false si hay espacios en blanco
input.value.trim() === ""  // true si solo hay espacios
// Usa siempre .trim() al validar
¿Qué hace cada ejemplo?

Cada bloque muestra el error típico y su solución. Son los fallos que más se repiten en los proyectos de clase.
